# @mufw/test

Model-based path testing for @mufw/core definitions. Part of [µFW](https://github.com/Trebh/microfw), the SAM pattern on Effect 4.

```sh
pnpm add effect @mufw/core
pnpm add -D @mufw/test
```

Documentation: [README](https://github.com/Trebh/microfw#readme) · [architecture](https://github.com/Trebh/microfw/blob/main/docs/ARCHITECTURE.md).
