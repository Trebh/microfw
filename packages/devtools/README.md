# @mufw/devtools

Time-travel panel, history list and Stately inspector adapter for @mufw/core. Part of [µFW](https://github.com/Trebh/microfw), the SAM pattern on Effect 4.

```sh
pnpm add @mufw/devtools @mufw/core effect uhtml
```

Documentation: [README](https://github.com/Trebh/microfw#readme) · [architecture](https://github.com/Trebh/microfw/blob/main/docs/ARCHITECTURE.md).
