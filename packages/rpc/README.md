# @mufw/rpc

Wire contract and remote adapters for @mufw/core ports, transport-free. Part of [µFW](https://github.com/Trebh/microfw), the SAM pattern on Effect 4.

```sh
pnpm add @mufw/rpc @mufw/core effect
```

Documentation: [README](https://github.com/Trebh/microfw#readme) · [architecture](https://github.com/Trebh/microfw/blob/main/docs/ARCHITECTURE.md).
