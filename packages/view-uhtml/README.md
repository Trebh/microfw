# @mufw/view-uhtml

Mounts a pure uhtml v4 view on a @mufw/core loop; keyed lists, input scheduler, SSR entry. Part of [µFW](https://github.com/Trebh/microfw), the SAM pattern on Effect 4.

```sh
pnpm add @mufw/view-uhtml @mufw/core effect uhtml
```

Documentation: [README](https://github.com/Trebh/microfw#readme) · [architecture](https://github.com/Trebh/microfw/blob/main/docs/ARCHITECTURE.md).
